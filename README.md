# 솔 야누스 키우기 — 모바일 포팅

기존에 웹(Claude 아티팩트)에서 작업하던 `솔 야누스 키우기`를 실제 모바일 앱(Android/iOS)으로
띄울 수 있도록 [Capacitor](https://capacitorjs.com/)로 감싼 프로젝트입니다. 게임 로직/데이터는
그대로 유지하고, 모바일 환경에 필요한 부분만 조정했습니다.

## 폴더 구조

```
www/                 실제 게임(웹 앱) 소스. Capacitor의 webDir로 지정된 폴더.
  index.html          게임 전체(HTML+CSS+JS, 원본 sol-janus.html을 모바일에 맞게 수정)
  manifest.json        PWA 매니페스트(홈 화면에 설치할 때 사용)
  icons/                앱 아이콘(192/512, apple-touch-icon, favicon)
android/              `npx cap add android`로 생성된 네이티브 안드로이드 프로젝트
ios/                  `npx cap add ios`로 생성된 네이티브 iOS 프로젝트
capacitor.config.json Capacitor 설정(webDir, 앱 ID, 배경색 등)
package.json          npm 스크립트 & Capacitor 의존성
```

## 웹에서 원본과 달라진 점 (모바일 적응)

1. **저장소**: 원본은 클로드 아티팩트 전용 `window.storage` API에 의존했는데, 실제 앱에는
   그 API가 없어서 새로고침/재실행할 때마다 계정·캐릭터 데이터가 사라졌습니다. 이제는
   `localStorage`를 기본으로 사용해서 앱을 껐다 켜도 데이터가 유지됩니다(`window.storage`가
   있는 환경, 예: 아티팩트 미리보기에서는 계속 그걸 우선 사용).
2. **뷰포트/세이프 에어리어**: `viewport-fit=cover`, 확대/축소 금지, 노치·홈 인디케이터를
   피하는 `env(safe-area-inset-*)` 패딩 적용. 당겨서 새로고침/바운스 스크롤 방지.
3. **레이아웃**: 원래 화면 오른쪽에 고정폭(280px) 사이드바로 있던 스탯/버튼을 지도 위에
   겹쳐지는 얇은 HUD(왼쪽 위: 이름·체력·골드, 오른쪽 위: 스탯창·캐릭터정보·인벤토리·스킬
   아이콘 버튼)로 바꿔서 좁은 폰 화면에서도 지도가 넓게 보이도록 했습니다.
4. **이동 조작**: 기존 화살표 키 이동은 그대로 두고(PC 테스트용), 왼쪽 아래에 가상
   조이스틱을 추가해 터치로 이동할 수 있게 했습니다.
5. **스킬 단축키**: 기존에는 키보드(Z/X/C/A/S/D)로만 스킬을 쓸 수 있었는데, 오른쪽 아래
   단축키 버튼을 탭하면 바로 시전되도록 클릭 핸들러를 추가했습니다.
6. **호버/더블클릭 → 탭/더블탭**: 장비 슬롯·인벤토리 칸·스킬 카드의 "마우스 올리면 설명,
   더블클릭하면 장착/해제/개봉" 동작을 터치에서도 쓸 수 있도록(한 번 탭 = 설명 미리보기,
   빠르게 두 번 탭 = 실행) 보강했습니다. PC의 마우스 hover/더블클릭 동작은 그대로 유지됩니다.
7. **터치 타깃 크기 확대**: 버튼/아이콘 크기를 44px 안팎으로 키우고, 모달 안전영역 패딩을
   추가했습니다.
8. **PWA 매니페스트/아이콘** 추가로 홈 화면에 설치해서 브라우저 주소창 없이 실행 가능.

게임 밸런스/데이터(경험치 테이블, 몬스터 스펙, 스킬, 세트 효과 등)는 건드리지 않았습니다.

## 브라우저에서 빠르게 테스트하기

```bash
npm run serve
# http://localhost:8080 을 열고, 브라우저 개발자도구의 모바일 기기 시뮬레이션으로 확인
```

## 실제 모바일 앱으로 빌드하기 (Capacitor)

사전 준비물: Node.js, 그리고 Android는 Android Studio(+ Android SDK), iOS는 macOS + Xcode.

```bash
npm install

# www/ 수정 후에는 항상 네이티브 프로젝트에 반영
npx cap sync

# Android
npx cap open android   # Android Studio가 열리면 Run 버튼으로 에뮬레이터/실기기 실행

# iOS (macOS 전용)
npx cap open ios       # Xcode가 열리면 Run 버튼으로 시뮬레이터/실기기 실행
```

`android/`, `ios/` 폴더는 이미 `npx cap add`로 한 번 생성해 둔 상태라 바로 위 명령어로
열어볼 수 있습니다. `www/index.html`을 수정한 뒤에는 반드시 `npx cap sync`를 실행해야
네이티브 프로젝트 쪽에도 최신 웹 코드가 복사됩니다.

## 알아두면 좋은 점

- 게임은 여전히 순수 HTML/CSS/JS 한 파일(`www/index.html`)로 되어 있어서, 굳이 네이티브
  앱으로 안 만들어도 `manifest.json` 덕분에 모바일 브라우저에서 "홈 화면에 추가"만 해도
  거의 앱처럼 전체화면으로 실행됩니다.
- 계정 시스템은 여전히 데모용(비밀번호 평문 저장, 기기 로컬 저장소 안에서만 유효)입니다.
  여러 기기 간 동기화가 필요해지면 실제 서버/DB 연동이 필요합니다.
